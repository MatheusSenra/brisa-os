BRISA OS

Pastas no cartão:
  Roms/<SISTEMA>   coloque os jogos aqui (GB, GBC, GBA, NES, SNES, MD, MS, GG, PS...)
  Brisa/bios       BIOS (ex.: PlayStation: scph5501.bin; Mega CD: bios_CD_U.bin)
  Brisa/saves      saves dos jogos
  Brisa/states     estados salvos
  Brisa/wifi.conf  rede Wi-Fi (veja wifi.conf.exemplo)

Botões:
  START na lista        Ajustes
  SELECT na lista       atualizar a lista de jogos
  MENU + cima/baixo     brilho (também durante o jogo)
  MENU + START          sai do jogo
  segurar START (2 s)   menu do RetroArch (no jogo)
  POWER                 menu de energia; no jogo, sai salvando

Rede (Ajustes > SSH e SFTP): usuário root, senha "brisa".
Troque a senha com "passwd" pelo SSH.
